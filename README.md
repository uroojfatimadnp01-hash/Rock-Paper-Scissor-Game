# Rock Paper Scissors Game

A classic, fun, and interactive Rock Paper Scissors web game built using HTML, CSS, and JavaScript. Play against the computer with real-time score tracking and immediate result feedback.

## 🚀 Live Demo


## 🛠️ Built With
* **HTML5:** For structured layout and game elements.
* **CSS3:** For styling, custom borders, and responsive design.
* **JavaScript (ES6):** For core game logic, computer random choices, and score updating.

## ✨ Features
* **Interactive Gameplay:** Clickable choices (Rock, Paper, Scissors) with clean UI feedback.
* **Score Tracker:** Keeps track of both "You" and "Computer" scores in real-time.
* **Computer AI:** Generates random choices for the computer opponent to ensure fair play.
* **Clean & Modern UI:** Simple layout designed for an engaging user experience.
